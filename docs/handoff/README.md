# 阶段交接文档（handoff）

本目录存放**每个 Phase 完成后的交接文档**，命名规则：`phase-N-complete.md`。

## 作用

1. 记录该 Phase 的产出、关键文件、数据/接口变更。
2. 作为下一阶段启动的上下文（配合根目录 `CONTEXT.md`）。
3. 沉淀「跨阶段需知」的关键决策，避免重复踩坑。

## 何时创建

每个 Phase 验收通过后，复制下方模板生成 `phase-N-complete.md`，并同步更新根目录 `CONTEXT.md` 的进度表。

## 模板

```markdown
# Phase N 完成交接

## 完成日期
YYYY-MM-DD

## Phase N 目标
<概述本阶段目标>

---

## Task N.1: <任务名>

### 产出
- <产出的模块/文件/能力>

### 关键文件
| 文件 | 职责 |
|------|------|
| `<path>` | <职责> |

### 验收结果
- <验收项> ✅ / ❌
- <验收项> ✅ / ❌

---

## Task N.2: <任务名>
<同上结构>

---

## 当前系统状态
- <环境/服务/数据状态>

## 关键技术决策（跨阶段需知）
1. <决策与理由>

## 下一阶段 (Phase N+1) 需要知道的
- <前提条件、遗留问题、注意事项>
```

## 说明

本项目当前尚未开始开发，本目录暂无 `phase-N-complete.md`。首个交接文档将在 Phase 0 验收通过后生成。
